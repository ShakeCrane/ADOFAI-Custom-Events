# Core 与事件包边界审计

Core 提供事件加载、原生编辑器接入、脚本时钟、资源管理与通用渲染能力。事件包持有参数、规则、脚本与素材。新增效果优先组合已开放能力，需要新宿主操作时再增加有明确输入、输出和清理语义的通用原语。开发者契约见 [`.event` 开发指南](EVENT-SDK.md)。

| 能力 | Core | 事件包 |
|---|---|---|
| 通用编辑与运行 | 发现、注册、双载体存档、沙箱、时钟、设置、缺包恢复、原生导出 | Manifest、参数默认值和语言、入口脚本 |
| 区域与计算 | 原生 depth、屏幕采样、GPU 图、后台像素任务、标签和缓存 | 噪域状态、触点、图、着色器、纹理、CPU 回退程序 |
| 视频 | 解码、画面与音轨、裁剪几何、装饰绑定、静态预览执行、兼容转换 | 视频开始时间、裁剪策略、循环和末帧策略、预览参数映射 |
| 全屏阶段 | 摄像机渲染挂钩、材质与变量、曲线插值、LUT 资源、声明式控件 | 调色 shader、调色时序、HSL 分区、预设、参数与控件绑定 |

正式构建排除 `Diagnostics/`。区域适配器中的部分历史名称沿用 `NoiseField`。当前高级角色的输入输出仍与 Core build 绑定，开发时用 SDK 的角色表和参考包对照。普通谱面无依赖时保持原生编辑器状态。

包从当前谱面目录加载。本机事件设置按 ID 隔离。包可以使用归档内资源，以及受宿主消费者约束的谱面相对媒体路径。视频转换使用玩家安装的 FFmpeg，并在转换完成后发布缓存文件。

2026-11-21 在 ADOFAI r150 / Windows D3D11 完成视频编辑器 51 项、真实游玩 3 项、调色 31 项、核心与噪域 156 项、谱面隔离与恢复 14 项。隐藏进程跳过 UMM 设置的人工鼠标检查。

## 实测与限制

- ADOFAI r150、Windows D3D11：空事件目录和只装噪域包均成功启动；单包注册噪域与状态控制两个入口。
- 游戏内覆盖三态、反转、原生 depth、两层合成、采样开关、GPU 故障后的 CPU 回退及旧数据迁移；触点规则以合成输入验证。原生面板隔离、稳定播放不重复烘焙和资源释放检查通过。
- 包内 GPU 计算、纹理与合成路径同迁移前实现做过逐像素对照；新旧 CPU 样本帧一致。这些对照用于确认解耦没有改变已有实现，不能单凭它们证明游戏中每一帧都与 Phira-Pro 完全相同。
- 在 RX 6750 GRE 上，用 1600×900、12 区域、3 个 depth 的游戏内离屏场景测量并强制 GPU 读回，单帧总耗时 P95：基线 0.72 ms、关闭采样 3.49 ms、开启采样 5.07 ms；这是同步读回的合成测试，不能直接当作实际游玩帧率或其他显卡的保证。
- 隐藏测试进程没有触发 UMM `OnGUI`，开关的实际鼠标操作未自动验证。多 GPU、多资源包同时运行、复杂谱面性能仍需更广泛验证；CPU 回退在大量快速变化区域的开销也未充分测量。

## 升级与兼容

本版 Core 需要配套 `pev.noise-field` **1.33.0 或更新版本**。旧谱面的事件 ID、参数和载体格式保持可读取；旧事件包缺少新的内部渲染资源或声明，须随 Core 一起升级。旧的内部 `fx.fieldState` 兼容调用已移除，新版状态事件使用通用标签数据。公开契约变更仍须按 SDK 规则处理，内部接线不承诺向旧事件包兼容。

正式分发为不含事件文件的 Core 压缩包及独立的 `NoiseField.event`、`Video.event` 与 `ColorGrading.event`。需要 shader bundle 的事件包已包含对应文件，玩家无需安装 Unity。更详细的视觉和环境限制见 [噪域 GPU 包验证记录](NOISEFIELD-RELEASE-VALIDATION.md)。
