# Core 与事件包边界审计

2026-11-16。原则：事件声明自己的设置和效果行为；Core 提供通用执行、存储、编辑器接入与可复用原语。不得声称目前所有历史耦合都已经清除。

## 本次已处理

- 全局开关由 schema 3 的事件包声明，Core 通用生成 UMM 面板、按事件 ID 保存并向 API 2 脚本提供快照。噪域采样开关的名称、默认值与文案移进噪域草稿包；Core 不再有噪域专属设置类或 UMM 控件。
- 原生装饰新建颜色由事件包的 `decorationDefaults` 声明，Core 按声明设置，不再按噪域事件 ID 设置红色；已有装饰行不被重写。
- 状态事件的预警时长及状态选择逻辑从 Core 的专用调度器迁至事件包脚本。Core 的字段原语提供按标签设置状态、处理多个来源优先级和销毁时撤销的能力。脚本、状态控件和实际事件实例已在游戏测试。
- 新增通用 `Choice` 参数：事件包声明选项和值，Core 为原生面板生成受限的数据枚举。噪域状态事件的选项定义和翻译均移入事件包，不再在 Core 写事件专用枚举；脚本沙箱没有获得 CLR 或反射权限。旧包如果引用的程序集枚举不再存在，而包内有完整、合法的选项标签和默认值，Core 可通用地用这些声明恢复下拉项，保留原有字符串值。
- GPU 实验渲染器根据包声明的原语和资源角色查找贴图、compute shader 与合成 shader，不再按事件 ID 或 Phira 素材文件名硬编码。当前只允许一个字段 shader 提供者；出现多个提供者会记录错误并回退，尚不能称为多事件自由组合。
- 实验 shader 的固定颜色、辉光、颗粒和位移默认值改由事件的 `fieldUniforms` 声明，触点闪烁的波形参数由 `fieldWaves` 声明；Core 只做类型、保留字段校验和通用绑定。不再内置这批视觉数值；已对照迁移前的 33 个浮点和 11 个向量字面量。实际 Unity 噪域 shader 仍须有效 bundle 验证。
- 旧评论事件迁移到装饰时，旧字段特有的尺寸换算和默认红色只对字段兼容路径执行，不再把字段的尺寸语义套到任意装饰事件。

## 仍需处理的边界债务

- `NoiseFieldRenderer`、`EditorPreview`、`LevelStorage` 和 `NoiseTextures` 仍有旧字段包的参数名转换、识别启发式、内嵌贴图与旧烘焙渲染路径。这些是历史谱面兼容代码，不是所有事件的通用约定；旧包尚不携带全部素材，删除前必须有可迁移的事件声明和旧谱面读写回归。
- `fx.field` 的计算、纹理和渲染生命周期是 Core 原语。当前实验实现仍针对参考噪域，且 Unity bundle、效果和多个不同字段资源提供者尚未验证；需要明确其可复用接口后才能视为稳定的公开能力。
- `Diagnostics/` 中按具体事件 ID 构造和检查测试数据是测试夹具，不参与一般事件的功能调度；它们不应成为生产功能依赖。

## 契约与测试

事件全局设置属于 schema 3、脚本 API 2；schema 1/2 和 API 1 仍可加载。设置属于本机，不写入谱面；卸载事件包保留其值。新增类型或改变语义须先更新契约、验证隔离和兼容性，不能因为某个具体效果临时扩大脚本权限。
