# 首发技术路线冻结

冻结日期：2026-11-18。实现基线：`4b04df3179ac3324f86d7de124965663ac62e9e2`；此后的发布准备可以补充文档、许可文件和打包检查，不改变已验收的运行行为。本记录用于后续改动的比较基线，不妨碍修复缺陷或按版本演进。

## 核心和事件的边界

- Core 是通用 UMM 模组，负责谱面事件加载、编辑器接入、脚本沙箱、资源读取与通用渲染能力。安装包不包含任何 `.event` 文件；没有事件及其依赖的谱面不注册事件或占位事件。
- 效果的参数、逻辑、状态、资源及全局设置声明归各自事件包。Core 依据包声明在 UMM 中提供设置，而不预设噪域专用开关。增加通用能力不意味着把具体事件固化进 Core。
- `.event` 是谱面素材，与 `.adofai` 放在同一目录；只从当前谱面目录加载，不使用模组全局目录回退。谱面以根字段 `pevEvents` 保存依赖，缺包时提醒并保留数据。原生导出包含已声明的事件包。
- 事件包 schema 4、脚本 API 2 和已有 `@PEV1` 载体的兼容性以 [事件开发指南](EVENT-SDK.md) 为准；变更公开契约前须考虑版本和旧谱面读取。具体边界见 [Core 审计](CORE-BOUNDARY-AUDIT.md)。

## 噪域效果

- 视觉参考固定为 Phira-Pro 提交 `c8fb11c6a41faaf1233a5affabf87b0223e2edd8`。包内 shader、素材、脚本和计算图共同形成当前路线；后续视觉问题先对照参考实现和可复现的画面，不凭观感猜算法。
- 噪域以原生装饰承载，遵循原生位置、变换、标签及 depth；状态事件按标签控制未激活、预警和激活，星球接触只产生视觉反馈。区域组合、反转和触点以当前事件实现为基线。
- 实时场景采样由事件包声明全局开关，默认开启；关闭时保留不采样路径，画面有所不同。GPU 路径依赖包内 shader bundle，失败时尝试 CPU 回退，玩家不需要 Unity 编辑器。
- 重计算使用后台任务、受限并发和资源生命周期管理；性能改动应保留有效画面并测量游戏内影响。

## 调色事件

- 全屏后处理挂在游戏实际出画面的摄像机上（`OnRenderImage`）：编辑器空闲时世界相机直接出屏，播放时同一台相机先渲染到 `camRT` 再由叠加四边形显示，两种情况都拿到合成后的完整画面；UI 在相机之后绘制，不受影响。
- 内核只提供渲染挂钩和统一变量搬运；shader、参数含义、曲线表与 LUT 都归 `ColorGrading.event`。这与噪域「Core 提供通用能力、事件持有具体效果」的边界一致。
- 曲线由控制点在 Core 侧烘焙成 256×1 查找表（单调三次插值，避免过冲），LUT 支持 `.cube` 的 1D/3D 形式并在释放时回收纹理。编辑器面板写回的是普通声明参数，因此保存、复制、分享与未安装模组时的打开行为都不变。
- 验证方式是可复现的画面基准：合成色卡经真实材质渲染后与 CPU 参考实现逐像素比较，另有时间轴淡入、叠加/替换、资源释放与异常输入用例。结果见提交记录与 `docs/EVENT-SDK.md` 中 `screenEffect` 一节。

## 已验证范围与变更规则

基线已在 ADOFAI r150、Unity 6000.3.25f1、Windows D3D11 的指定硬件环境测试。游戏内覆盖三态、组合、depth、采样与回退；谱面目录加载、跨谱面隔离、缺包提醒、依赖保存及原生导出也已实测。2026-11-18 的谱面加载回归 14 项和原有游戏内回归 115 项通过；后者的 UMM 设置界面鼠标操作在隐藏进程中跳过。详细证据、参考比较方式与限制见 [发布验证记录](NOISEFIELD-RELEASE-VALIDATION.md)。

现有比较不证明所有 GPU、所有谱面或 Unity 完整画面与参考逐帧相同；关闭采样也不与开启采样等价。实机性能结果只代表记录中的条件。

修改效果或合成路径时，先确定对照样例和验收指标，再运行相关游戏内回归；修改 Core 与事件边界或谱面存储时，还需验证旧数据保留、缺包恢复、空谱面及导出。任何发布版本应固定源码提交、独立列出 Core 与事件版本，并重新校验最终文件。
