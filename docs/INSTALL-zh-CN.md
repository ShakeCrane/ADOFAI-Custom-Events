# PEV.Core 安装与噪域使用

1. 使用与本包兼容的 Unity Mod Manager 安装压缩包，或将压缩包中的 `PEV.Core` 文件夹放入游戏的 `Mods` 目录。升级时同时更新 Core 和其中的 `Events`，不要只替换 DLL。
2. 在 UMM 中启用 PEV.Core。进入谱面编辑器，在事件列表中添加“噪声域”，像原生装饰一样调整位置、大小、旋转、颜色、透明度、depth 和标签。
3. 需要改变状态时，添加“噪域状态”事件，输入目标标签并选择未激活、预警、激活或预警后激活。标签为空时不影响任何噪域。
4. 噪域事件的“实时场景采样”设置在 UMM 的事件设置中，默认开启。关闭后仍有透明混合，但不使用实时背景采样，视觉和性能会有所不同。

旧谱面的事件数据继续保留。旧版噪域面板参数标记为弃用，GPU 路径按参考效果运行，不保证这些参数继续改变画面。shader bundle 已随事件包提供，玩家不需要安装 Unity 编辑器。

本包已在 ADOFAI r150 / Unity 6000.3.25f1 / Windows D3D11 测试。GPU 设备、游戏版本和谱面复杂度不同可能产生不同结果；如果 GPU 初始化失败，事件会尝试回退到旧 CPU 渲染路径。
