# PEV.Core 与独立事件安装

1. 使用 Unity Mod Manager 安装 Core 压缩包，或将其中的 `PEV.Core` 文件夹放入游戏的 `Mods` 目录。Core 的发布包不预装事件。
2. 将独立的 `NoiseField.event` 放在要使用它的 `.adofai` 文件旁边。在 UMM 中启用 PEV.Core，打开或重新打开该谱面，使用“添加噪域”放置区域。装饰列表中显示为 `NoiseField`。
3. 需要改变状态时，先给目标噪域填上标签，再添加“更改噪域状态”事件，输入同一标签并选择未激活、预警、激活或预警后激活。新放置的噪域标签留空。
4. 噪域事件的“实时场景采样”设置在 UMM 的事件设置中，默认开启。关闭后仍有透明混合，但不使用实时背景采样，视觉和性能会有所不同。

保存时谱面会记录事件依赖，游戏的谱面导出会将已声明的事件包一并包含。缺少事件包时左上角会提醒，原有事件数据仍保留；将正确文件放回谱面目录并重新打开即可恢复。只搜索当前谱面所在目录，不使用模组目录中的全局事件包。

升级旧谱面时，同时换用新版 Core 和谱面目录里的事件包。旧参数已从面板移除，其谱面数据仍保留。噪域使用自己的合成方式，因此面板不显示原生混合模式。

海岸线、边缘和触点大小随世界坐标缩放。触点透明度和大小取星球实际接触的区域，任一设为 `0` 都会关闭该区域的触点。重叠区域按装饰顺序取第一个有效区域。相同深度共用边缘合成和动画时间，宽度取排序最先的非反转区域，动画速度取第一个偏离默认值的非反转区域。动画速度 `1` 为原速，`0` 冻结噪域纹理和粒子动画。shader bundle 已随事件包提供，玩家无需安装 Unity 编辑器。

本包已在 ADOFAI r150 / Unity 6000.3.25f1 / Windows D3D11 测试。GPU 设备、游戏版本和谱面复杂度不同可能产生不同结果；如果 GPU 初始化失败，事件会尝试回退到旧 CPU 渲染路径。

## 视频事件

1. 将 `Video.event` 和视频素材放在 `.adofai` 旁边，重开谱面并添加“视频”装饰。在参数面板选择文件，使用相对谱面的路径。
2. 用原生装饰工具调整位置、缩放、旋转、透明度和深度。填写标签后可用 `MoveDecorations` 控制。缩放方式“完整显示”会保留比例，“填满并裁切”会居中裁至原装饰框，“拉伸”会铺满原框。
3. 起始拍相对放置格，可为负值，按该格 BPM 换算。裁剪起止用媒体秒数，终点为 0 时播至片尾。按需选择速度、循环、结束保持帧与音量，视频默认静音。
4. 游戏导出会包括同级的视频与包。视频放在子目录时，使用可保留其相对目录的归档方式，并检查发布文件。

解码能力由 Unity 和系统解码器决定。转换使用本机安装的 FFmpeg，放在模组目录或 PATH 上，转换缓存位于 `Mods/PEV.Core/video-cache/`。透明视频受当前解码后端限制。格式矩阵与具体实测条件见[视频验证记录](VIDEO-VALIDATION.md)。

## 调色事件

1. 将 `ColorGrading.event` 与 `.adofai` 放在同一目录，重开谱面，从 VisualFx 添加“调色”。
2. 在原生面板设置曝光、影调、强度、淡入与组合方式。淡入时长为相对事件所在格的拍数。“替换”切换较早的替换层，“叠加”在已有画面上增加一层。
3. 在独立面板编辑曲线、色轮、LUT 和 HSL 分区。A/B 控制当前事件的开关，Scopes 提供直方图、RGB Parade、波形和矢量示波器。
4. 使用内置 LUT，或选“无”后在自定义文件框填写 `.cube` 相对路径。包外 LUT 与谱面一同分享，导出后确认它在归档中。预览显示稳定后的效果，实际淡入时序用试玩确认。

事件开发规则见 [`.event` 开发指南](EVENT-SDK.md)。
