# PEV.Core 与独立事件安装

1. 使用 Unity Mod Manager 安装 Core 压缩包，或将其中的 `PEV.Core` 文件夹放入游戏的 `Mods` 目录。Core 的发布包不预装事件。
2. 将独立的 `NoiseField.event` 放在要使用它的 `.adofai` 文件旁边。包内同时包含噪域和标签状态控制两个事件入口。在 UMM 中启用 PEV.Core，打开或重新打开该谱面，即可在编辑器中添加“噪声域”，像原生装饰一样调整位置、大小、旋转、颜色、透明度、depth 和标签。
3. 需要改变状态时，添加“噪域状态”事件，输入目标标签并选择未激活、预警、激活或预警后激活。标签为空时不影响任何噪域。
4. 噪域事件的“实时场景采样”设置在 UMM 的事件设置中，默认开启。关闭后仍有透明混合，但不使用实时背景采样，视觉和性能会有所不同。

保存时谱面会记录事件依赖，游戏的谱面导出会将已声明的事件包一并包含。缺少事件包时左上角会提醒，原有事件数据仍保留；将正确文件放回谱面目录并重新打开即可恢复。只搜索当前谱面所在目录，不使用模组目录中的全局事件包。

升级旧谱面时，将所需事件包放在谱面文件旁。旧版噪域面板参数标记为弃用，GPU 路径按参考效果运行，不保证这些参数继续改变画面。shader bundle 已随噪域事件提供，玩家不需要安装 Unity 编辑器。

本包已在 ADOFAI r150 / Unity 6000.3.25f1 / Windows D3D11 测试。GPU 设备、游戏版本和谱面复杂度不同可能产生不同结果；如果 GPU 初始化失败，事件会尝试回退到旧 CPU 渲染路径。
