# 噪域 GPU 包验证记录

2026-11-16。Unity 6000.3.25f1 使用已激活的许可证构建 Windows shader bundle；事件包内含该 bundle，无需玩家安装 Unity。GPU 原语按包自动加载，失败时回退 CPU 路径；状态事件与场景采样设置均由事件包声明。

2026-11-18 补充：核心与事件拆分后再次运行实际游戏回归，以及参考帧 D3D11 对照。开启采样的对照包含三态、颜色和触点；最坏案例有 276/36864 个 RGB 像素不同，平均通道误差 0.0375/255。关闭采样按设计不采样背景，不以采样路径画面作为等价标准。1600×900、12 区域、3 个 depth 的离屏同步读回测量，帧耗时 P95 分别为基线 0.72 ms、采样关闭 3.49 ms、采样开启 5.07 ms；这不等于实际谱面的 FPS。

实机环境：ADOFAI r150，Windows，Direct3D 11，Gamma，1600×900，AMD Radeon RX 6750 GRE 10GB。自动启动游戏的测试验证了 11 个 bundle 资源加载、GPU 自动接管、单层 depth 前景遮挡、不同 depth 双层合成、背景采样与关闭采样、Active/Ready/Disabled 三态、重叠反转镂空及状态事件面板与脚本。完整 PN1 播放回归通过编辑器预览、动画、空闲 CPU 烘焙、清理和截图检查。

独立 D3D11 掩膜、颜色归属、触点与效果样本对照通过；简化条件下的整帧对照与参考非常接近，但部分像素有差异。它不是 Unity 游戏内完整画面的逐帧等价证明。

尚未完成：真实社区谱面与其他 GPU 的覆盖，完整 Unity 游戏画面与参考逐帧对照，以及多个不同有效 shader bundle 同时运行的验证。上述多 depth 性能数据只覆盖单机合成场景。隐藏测试进程未触发 UMM `OnGUI`，因此开关面板的鼠标操作仍需人工确认。不能据此宣称所有场景都严格一致。
