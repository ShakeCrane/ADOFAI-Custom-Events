# 首发说明草稿

> 草稿，尚未发布。当前候选：PEV.Core 0.6.0，NoiseField.event 1.33.0。最终名称、版本和发布时间由发布者确定。

PEV.Core 为《冰与火之舞》提供可插拔的自定义事件支持。此版本同时提供独立的噪域事件包，可在谱面编辑器中像装饰一样放置和调整噪域，并使用标签控制状态。

## 下载与安装

1. 下载 `PEV.Core-0.6.0.zip`，使用 Unity Mod Manager 安装并启用。
2. 如需噪域，另行下载 `NoiseField.event`，放在对应谱面的 `.adofai` 文件旁，然后打开或重新打开谱面。
3. 编辑器中的“噪声域”用于放置区域，“噪域状态”按标签控制状态；事件的实时场景采样设置位于 UMM 中，默认开启。

Core 不自带事件包。每张谱面只使用自己目录中的事件包，缺少依赖时左上角会显示提醒。保存后的谱面会记录依赖，原生导出会包含已声明的事件文件。

## 兼容与说明

- 已测试环境：ADOFAI r150、Windows、Direct3D 11；其他版本、显卡和复杂谱面仍需更多验证。
- 噪域视觉以 Phira-Pro 为参考，采样关闭时与默认开启的效果不同。shader bundle 包含在事件包中，使用者不需要安装 Unity。
- 旧谱面数据会保留。使用旧版噪域谱面时，应将与当前 Core 配套的事件包放在谱面文件旁。
- 游戏内自动测试未覆盖 UMM 设置界面的实际鼠标操作；首次发布前宜在可见窗口确认。

项目源码和许可证随仓库提供；事件包包含 Phira-Pro 相关来源说明及许可，Core 包包含其随附第三方组件的许可声明。问题反馈请附游戏版本、日志和可复现谱面。
